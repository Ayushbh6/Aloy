# Approved companion design

`aloy-presence.html` is the approved interactive reference, saved from the design
conversation on 25 September 2026. It is a reference fragment, not an application
entry point or a second agent frontend.

Visual thesis: a soft, living particle presence with precise typography, calm
sage/charcoal or warm-light surfaces, and minimal chrome.

Content hierarchy: presence → current exchange → desktop explanation → durable
conversation. Keep technical inspection and preferences out of the compact bubble.

Interaction thesis: all orb states keep the Thinking state's curved distribution;
motion changes signal activity. The bubble unfolds near the orb. A visual explanation
opens on the desktop and remains available from the full conversation app.

The user approved the complete reference, requesting only that Quiet and Needs you
use the Thinking shape too. Do not reintroduce a glossy sphere, hard rim, spiky
jitter, listening stretch, oversized control panel, or permanently visible inspector.

The reference's sample lesson is illustrative. Production content must come from
the canonical agent and validated artifact events, with one conversation identity
across every surface. No generated executable code or automatic application closing.
